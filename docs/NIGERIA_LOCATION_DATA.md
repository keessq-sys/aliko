# Nigeria location catalogue

Source: [Open Admin Data Nigeria administrative divisions](https://github.com/open-admin-data/nigeria-administrative-divisions), accessed 3 October 2026. Data licensed [CC-BY-4.0](https://creativecommons.org/licenses/by/4.0/).

Adaptations: retained names only, grouped the 774 LGAs by their parent state, sorted names, and displayed Federal Capital Territory as FCT Abuja. Includes 36 states and Abuja FCT (six area councils). Local selectors do not depend on a remote API being available.
